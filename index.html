🚀 My first deployment — the 7 tools cheat sheet

This page exists because I learned what these tools do, then shipped it through the whole pipeline.

Git — a version recorder on your own computer. Every change is a save point you can roll back to.
GitHub — a website that hosts Git repositories online: backup, collaboration, portfolio.
Node.js — a runtime that lets JavaScript run outside the browser, on your machine or a server.
Next.js — a framework for building websites fast with React/JavaScript; the scaffolding is pre-built.
Vercel — a deployment platform: push code to GitHub and your site goes live on the public internet automatically.
Supabase — a ready-made backend: database, auth, and file storage without writing your own server.
Cloudflare — DNS, CDN acceleration, and security standing in front of your site.

Write code → Git records versions → Push to GitHub → Vercel deploys it live → Data lives in Supabase → Visitors reach it fast and safely via Cloudflare
